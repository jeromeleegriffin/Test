What this fixes
The working ROOK044 room cleanup is now on the live 531 table.
Leaving an offline game could leave a stale room flag behind. The next Play with Friends press could then fail to open a clean host table, or the lobby could still look like a room was open.

What changed
- An offline table no longer saves a multiplayer rejoin session.
- Leave clears the saved room, the active-table flag, the rejoin button, and any room code in the address before it returns to the lobby.
- Play with Friends clears leftover offline / no-service flags before it hosts.
- Only game.js and polish.js changed. Cards, bidding, bots, and the lobby look are the same.

Please check these three paths
1. From the lobby, tap Play with Friends. You should land in the waiting room as host, with a room code, and not in an offline game.
2. Tap Leave. You should be back on the lobby. There should be no Rejoin button and no old room code.
3. Tap Play now (offline bots). Confirm you are in a game. Tap Leave. Then tap Play with Friends again. That second host should open a new waiting room, not bounce back to the offline table and not offer rejoin for OFFLINE.

If the phone still behaves the old way
Close the tab completely and open the live link again. The label will still say v531. This fix is inside that build. A phone that played offline earlier may be holding the old script until that fresh open.
